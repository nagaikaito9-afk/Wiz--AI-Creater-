           SupabaseのGoogleログインについて
          

            
※現在Supabase側でGoogleプロバイダがOFF（未設定）のため、Googleログインを押すとエラーになる場合があります。

            
    
              
  1. Supabaseダッシュボードを開く
    2. 
              
  2. Authentication > Providers > Google をONにする
    3. 
              
  3. Google Cloud Consoleの Client ID と Secret を設定
    4. 
            

            
設定完了までは、上記の「メールログイン」または「テストアカウント」で全機能をご利用いただけます。
