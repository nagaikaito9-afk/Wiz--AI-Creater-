# AIゲーム作成 (Wiz AI Game Creator) 🧙‍♂️✨

AI賢者 **Wiz (ウィズ)** と共にWebゲームやPythonプログラムを対話形式で企画・制作・編集・リアルタイム実行できる次世代型ゲーム開発スタジオです。

---

## 🌟 主な特徴

### 1. 賢者AI「Wiz」との対話
- **名前の由来**: Wizard（賢者・魔法使い）。ゲーム開発、数学、プログラミング、演出の深い知識を持つ賢者。
- **親しみやすさ**: Google Geminiのように気さくでフレンドリーな開発アシスタント。
- **今開いているプロジェクト専用の開発専任AI**:
  - 通常の世間話や無関係な雑談（通常会話）を廃止し、現在開いているプロジェクトの開発作業に特化。
  - プログラムの実行プレビュー、ファイルの作成・編集・削除、フォルダ操作、デバッグ、画像アセット生成など、プロジェクト開発に必要なすべての操作を自律実行。
  - 作成・編集した内容はWiz自身の言葉で自然にチャットで伝えてくれます。

### 2. ファイル・フォルダ添付 (最大5個)
- ドラッグ＆ドロップまたはファイル選択から一度に最大5個までのファイル・フォルダを添付可能。
- ソースコードや画像アセットの内容をAIが自動解析して開発に活用。

### 3. 収納可能な右側コードタブ (Web IDE)
- ファイルツリー（新規ファイル作成、フォルダ作成、リネーム、削除、個別ダウンロード）。
- リアルタイムシンタックスハイライト（HTML, CSS, JavaScript, Python, C++）。
- 行番号表示、タブ切り替え、Ctrl+Sによる保存。
- ワンクリックまたはショートカットキー `Ctrl+B` で瞬時に折りたたみ（収納）/ 展開が可能。
- **右クリックコンテキストメニュー**: 範囲選択して右クリックで「カット」「コピー」「ペースト」「Wizに質問」が利用可能。

### 4. プログラム実行機能 (Runner)
- ヘッダーの **「実行」** ボタン、またはショートカット `Ctrl+Enter` で即座にプレビュー起動。
- デフォルトは `index.html`（HTML/CSS/JS）。相対パスのCSS/JS参照を自動バンドルして安全にiframe sandboxで動作。
- `.py` (Python) ファイルはブラウザ内WebAssembly (Pyodide) を用いてリアルタイムにコンソール実行。
- チャット内から「このプログラムを実行して！」「○○フォルダの中のindex.htmlを実行して！」と指示するだけでも即実行。

### 5. 外観テーマ変更 (Google設定準拠: ダーク / ホワイト / グレー)
- ヘッダーのパレットアイコン（🎨）から、Google Design Systemと同一のダーク（`#202124`）、ホワイト（`#ffffff`）、グレー（`#2f3336`）の3テーマを瞬時に切り替え可能。

### 6. 音声読み上げ & コピー
- 各メッセージに音声読み上げ（Text-to-Speech）とコピー機能を搭載。コードブロックごとのコピーも可能。

### 7. インテリジェント画面キャプチャ＆操作
- **「○○フォルダ内のindex.htmlを実行して『スタート』ボタンを押したら何が出てくるか画像を送って」** といった詳細リクエストにも対応！
- 指定要素をクリック・操作した後の状態を自動レンダリングし、スクリーンショット画像（PNG）をチャット内に投稿・解説してくれます。

### 8. 🏠 部屋（プロジェクト）ごとのプログラム完全分離
- **各部屋独立VFS**: 部屋（プロジェクト）ごとに仮想ファイルシステム（LocalStorage `wiz_vfs_room_{roomId}`）が完全に独立。
- **プログラムの安全性**: ある部屋でコードを追加・編集しても、他の部屋のプログラムには一切影響を与えません。
- **瞬時スイッチング**: 部屋を切り替えるだけで、その部屋専用のHTML、CSS、JavaScript、C++などのコード一式がエディタとプレビューに即時ロードされます。

### 9. 💬 チャットへのコード貼り付けスマート対応 ＆ 忠告機能
- **自動ファイル反映**: ユーザーがチャット欄に直接コードを貼り付けた際、AIがコードを自動検知して適切なプロジェクトファイルに即座に反映。
- **長文コードのオウム返し防止**: チャット本文にコード全文を復唱せず、変更内容を簡潔に報告。
- **親切な忠告・アドバイス**: 「次回からは右側のコードエディタに直接書くか、クリップ添付（📎）を使うとさらにスムーズだよ！」とAIが優しくアドバイスを提供します。

### 10. 🎨 全画面統一UI & フルページ化 (1P:ホーム, 2P:プロジェクト, 3P:フレンド, 4P:マーケット, 5P:設定, チュートリアル)
- **Googleカラー統一**: ダーク（`#202124`）、ホワイト（`#ffffff`）、グレー（`#2f3336`）、Googleブルー（`#1a73e8`）で統一。
- **ヘッダー整理**: Wiz Studioロゴクリックでいつでもホーム画面へ移動。スタジオ専用アクション群はエディタ画面のみに表示。
- **フルページマーケット & 設定**: コミュニティゲーム共有広場と高機能設定画面をフルページで完備。

### 11. ↩️ ファイル・フォルダ変更の取り消し (Ctrl+Z) / やり直し (Ctrl+Shift+Z)
- ファイルのテキスト編集、ファイル・フォルダの新規作成、削除、リネーム履歴をスタック管理。
- `Ctrl+Z` で取り消し、`Ctrl+Shift+Z` / `Ctrl+Y` で直前の操作を自在にやり直せます。

### 12. 🖱️ サイト内全域の完全右クリック（コンテキストメニュー）対応
- ファイルツリー、コードエディタ、プロジェクトカード、フレンドカード、一般背景など、クリック場所に応じた最適なGoogleデザインのメニューを表示。

## 🖥️ Windows デスクトップアプリ (Electron)

本プロジェクトは **Web版（Vercel）とWindowsデスクトップ版（.exe）の両立構造** を採用しています。

### 1. デスクトップ版の起動 (開発モード)
```bash
npm install
npm start
```

### 2. Windows 用インストーラー & ポータブル版のビルド (.exe)
```bash
npm run build:win
```
ビルド完了後、`dist/` フォルダ配下に以下が自動生成されます：
- **`Wiz AI Creater Setup 1.0.0.exe`**: Windows用標準インストーラー (NSIS)
- **`Wiz AI Creater-1.0.0-Portable.exe`**: インストール不要で即起動できるポータブル実行ファイル

### 3. セキュリティアーキテクチャ
- **完全サンドボックス**: `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true` を徹底。
- **秘密鍵秘匿**: Gemini APIおよびResendのAPIキーはクライアント（Electron）内に一切含めず、Vercel Serverless API（`https://wiz-ai-creater.vercel.app/api/chat`）経由で安全に通信。
- **安全なゲーム実行**: ユーザーやAIが生成したプログラムは、既存のChromium内サンドボックス（`iframe`）で安全に隔離実行されます。
